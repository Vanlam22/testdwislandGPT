# 典華幸福島

為典華同仁設計的互動探索網站。以原創的 3D 浮島、人物與酒紅／香檳金介面，呈現八個同仁必讀主題。

## 開發與執行

需要 Node.js 22.12+（本環境已使用 Node.js 24 驗證）。

    npm ci
    npm run dev

預設開發埠為 5173。正式靜態檔案可用以下指令產生：

    npm run build
    npm run preview

將 dist/ 目錄部署至靜態網站主機即可。程式不需要 API 金鑰、資料庫或外部圖像服務；所有島嶼及人物都由本地程式產生，使用裝置內建中文字型。

### 用手機開啟

本機或雲端開發伺服器啟動成功，並不會產生可從手機連線的網址。工作區的檔案路徑、localhost、127.0.0.1 與雲端機器的私有 IP 都不能當作手機用的公開網址。發布 Codex 雲端環境也不會部署網站。

需要將 dist/ 的內容上傳到可存取的 HTTPS 靜態網站空間，再由手機開啟該平台提供的網址。建置已使用相對資源路徑，因此可以放在網域根目錄或子目錄。可使用公司網站主機、GitHub Pages、Vercel 或 Netlify；目前尚未部署至任何對外網址。

使用一般主機時，應上傳 dist/ 內的 index.html、favicon.svg 與 assets/，保留它們的相對位置。使用 Netlify 手動部署時，可在登入平台後上傳整個 dist/ 資料夾，取得平台產生的 HTTPS 網址。不要將壓縮檔或 index.html 直接當成手機瀏覽入口。

### 使用本專案的 GitHub Pages

原始碼使用 `codex/denwell-happiness-island` 分支；可直接供瀏覽器載入的建置檔使用 `gh-pages` 分支。`gh-pages` 根目錄含有 `index.html`、`assets/`、`favicon.svg` 和 `.nojekyll`，不需要在 GitHub 另外安裝 Node.js 或執行建置。

第一次啟用時，使用儲存庫管理員帳號：

1. 開啟 https://github.com/Vanlam22/testdwislandGPT/settings/pages 。
2. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
3. 在 **Branch** 選 **gh-pages**，資料夾選 **/ (root)**，按 **Save**。
4. 等待 GitHub 顯示部署完成，再開啟該頁面提供的 **Visit site** 連結。

預期網址為 https://vanlam22.github.io/testdwislandGPT/ 。只有 Pages 啟用並完成部署後，這個網址才會提供網站。此版本的 Pages 網站可由任何取得網址的人開啟；內容是探索導引與既有同仁網站連結，未包含內部規章全文。

後續更新需重新執行 `npm run build`，再將 `dist/` 的建置結果更新至 `gh-pages`；僅更新原始碼分支不會自動更新網站。

若雲端環境的預設 npm 快取目錄不可寫入：

    npm ci --cache /tmp/denwell-npm-cache

## 操作

- 點選島名、3D 建築或「島嶼目錄」，角色會前往該島並開啟探索導引。
- 關閉導引後，使用 WASD 或方向鍵在目前島上移動；手機可按住螢幕方向鈕。
- 按 E 再次開啟目前島嶼導引，按 Esc 關閉對話框。
- 「我的角色」可編輯名字、膚色、髮型、髮色與服裝。
- 前往同仁網站閱讀正式內容後，勾選閱讀確認並完成該站。探索進度與角色存於這個瀏覽器的 localStorage。
- 可以縮放地圖、回到幸福廣場、查看探索旅程或切換環境音。
- 無 WebGL 的裝置會顯示可操作的島嶼列表；支援偏好減少動態效果的系統設定。

## 參考資料與目前範圍

設計需求參考政策島的探索概念。初次製作時，雲端網路政策阻擋 puma.taipei、www.denwell.com 與 sites.google.com，因此無法核對原站互動、典華的正式色碼或擷取內部條文。此版是可運作的原創實作；目前配色及 D 字標為暫定的視覺提案，並非已取得的官方品牌素材。開放參考網站後仍需核對配色與內容。

目前沒有帳號登入、多人同步、後台管理或人資閱讀紀錄回報。完成狀態是同仁自行確認並保存在本機，不能用作正式的教育訓練或法定閱讀紀錄。若之後內嵌內部資料，部署時需另外配置公司的身分驗證與存取控制。

## 驗證

    npm test

Playwright 在此雲端環境使用 /usr/bin/chromium。其他環境若尚未安裝相容瀏覽器，先執行：

    npx playwright install chromium

測試涵蓋 3D 地圖、鍵盤與手機方向控制、角色編輯及保存、八個主題的閱讀確認、重新載入後的進度、手機版對話框和無效本機資料處理。

## 專案結構

- src/App.jsx：介面、角色編輯、主題面板與進度。
- src/World.jsx：Three.js 場景、島嶼模型、角色移動與觸控。
- src/data.js：主題資料、來源網址與本機資料驗證。
- src/styles.css：品牌視覺、桌面與手機版樣式。
- tests/island.spec.js：瀏覽器端功能測試。
